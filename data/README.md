# Dados científicos

Armazenamento a ser implementado conforme `planning/04_SCIENTIFIC_DATA_CONTRACT.md`.

Dados científicos não serão preenchidos com valores inventados. `EXTRAIDO_NAO_REVISADO` não equivale a `CONFERIDO_FONTE`. Dados observados pela NASA devem ser diferenciados de inferências e saídas numéricas.

Dados reais serão adicionados em fases posteriores, após revisão de fonte.
